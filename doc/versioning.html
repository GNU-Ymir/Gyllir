Versioning

Bump the version, tag it, and push the tag where other packages can depend on it.

Bumping a version

gyllir bump                              # bumps the patch: 1.2.3 -> 1.2.4
gyllir bump --minor                      # 1.2.3 -> 1.3.0
gyllir bump --major                      # 1.2.3 -> 2.0.0
gyllir bump --set 2.0.0                  # any numbered version

gyllir bump rewrites version in gyllir.toml, and nothing else. --commit also commits gyllir.toml (and only it), --tag tags that commit v<new version>, which implies --commit, and --dry prints what would happen without changing anything:

gyllir bump --minor --tag -m "Release 1.3.0"
git push origin master v1.3.0

A named version (version = "nightly") has nothing to increment: set a numbered one with --set. See the command reference for every flag.

gyllir.toml is rewritten, not patched. It is serialized from the parsed manifest, so comments and key ordering in the file are not preserved across a bump. Keep anything you care about in version control.

Versions and tags

The tags are the source of truth: when another package declares a version filter, Gyllir reads the tag list of your repository and picks the highest tag that passes. So a version only becomes usable once its tag is reachable at the URL the dependent package declares.

Tags may be written 1.2.0 or v1.2.0 — gyllir bump --tag writes the v form.

Keeping a version constant in sync

If your code has to know its own version, do not maintain a second copy by hand — generate it from the manifest with a pre-build command. That is what Gyllir itself does:

[commands]
set-version = { cmd = "./tools/set-version.sh", post = false }

The script reads version out of gyllir.toml and rewrites the constant in the sources, before every build.

Depending on a local checkout

No remote is needed to try a version out: another package can depend on your checkout directly, which is resolved by version like any other dependency — it has to be a git repository, and its tags are what the filter is matched against:

[dependencies.mylib]
version = ">=0.2.0"
url = "local:/home/jane/src/mylib"
